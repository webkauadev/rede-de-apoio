# Rede de Apoio — Contexto do Projeto

## Produto
Aplicativo mobile-first para organização do cuidado de uma pessoa idosa envolvendo familiares e profissionais da saúde.

## Objetivo
Centralizar plantões, calendário, diário de cuidados, medicamentos, tarefas, compromissos, histórico, contatos, emergência e auditoria.

## Princípios
- rastreabilidade RF → US → Tela → Estado → Componente;
- consistência visual acima de criatividade;
- dados sensíveis com controle de acesso;
- registros de cuidado preservados.

## Categorias
- Familiar (Principal, Apoio, Emergência);
- Profissional da Saúde;
- Pessoa Idosa (acesso próprio somente leitura — extensão em formalização).

## Regra importante
Plantonista Atual não é usuário. É uma condição operacional temporária do plantão.
