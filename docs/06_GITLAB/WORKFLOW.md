# Workflow GitLab

Fluxo recomendado:

Opened
↓
Doing
↓
Review/Validation
↓
Closed

## Métricas

Preservar histórico de movimentação.

Evitar mover issues apenas para organizar visualmente, pois isso impacta métricas.

## Definition of Done

Antes de fechar:

- requisito atendido;
- US validada;
- protótipo atualizado quando aplicável;
- rastreabilidade preservada.
