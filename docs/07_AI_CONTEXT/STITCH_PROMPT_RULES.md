# Stitch Prompt Rules

Before generating screens:

1. Identify RF.
2. Identify US.
3. Identify screen Txx.
4. Identify user permission.
5. Identify state.

Always preserve:

- same page shell between states;
- same typography;
- same spacing;
- same components;
- same navigation.

Rule:

STATE = PAGE BASE + DELTA MÍNIMO

Never create independent designs for Default, Error, Loading or Empty states.

Every prompt must include:
- project context;
- responsible person;
- mobile reference;
- existing components;
- allowed actions;
- forbidden actions.
