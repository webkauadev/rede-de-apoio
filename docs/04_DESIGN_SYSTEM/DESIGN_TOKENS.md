# Design Tokens

## Tipografia

- Geist.
- Títulos com alta hierarquia.
- Texto secundário com menor contraste.

## Espaçamento

Escala preferencial:

4, 8, 12, 16, 20, 24 px.

## Cores base

- Background: #FBF8FF
- Primary: #00567C
- Brand: #2A6F97
- Border: #E5E5E5
- Surface: #FFFFFF

Tokens devem ser reutilizados entre telas.
