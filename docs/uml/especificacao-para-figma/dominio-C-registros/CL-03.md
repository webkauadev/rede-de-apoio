Nota obrigatória junto de C-C10: `{exatamente um pai entre RegistroCuidado, Consulta ou AdministracaoMedicamento}`. Essa restrição global torna mutuamente exclusivos os três valores `0..1` do lado de `Anexo`: um deles é `1` para cada anexo persistido e os outros dois são `0`. Ela expressa `ck_anexo_pai` sem transformar o anexo em composição tripla. Todas as associações contínuas usam multiplicidades nas extremidades; não há losango porque retenção/ciclo de vida não foi estabelecido como semântica UML.

## Revisão AUD-M2-010 (2026-10-16)

Para confrontar SQ03-M03 e SQ01-M05, as assinaturas de `AdministracaoMedicamento.registrar(realizadaEm: DateTime, autor: Usuario)` e `Auditoria.registrarEvento(resultado: ResultadoOperacao, contextoSanitizado: String)` explicitam os parâmetros modelados nas sequências. `Usuario` aqui denota a referência conceitual de autoria; `ResultadoOperacao` é tipo de domínio existente. Assinaturas não representam API definitiva de implementação e retornos não comprovados não foram inventados. Outras operações abreviadas permanecem no nível de abstração indicado pelo contrato.
