# SQ-03 — Sequência: Administração de Medicamento

Status: **PRONTA PARA VALIDAÇÃO**. Cenário: usuário com permissão efetiva registra administração; o fato permanece imutável e N03 é disparada. A correção é mostrada como referência de pós-condição, não fluxo completo alternativo.

Fontes: [REQUISITO] RF16/US-019 CA #5673849778, RF25/US-029 CA #5673861716, RN-005/RN-006/RN-010 e RNF02; [PERSISTENCIA] administração/ocorrência no SQL V1; [ACADEMICO] slides 28–39/34. Critérios aprovados não estão formalizados em Gherkin; não inventar sintaxe Gherkin.

Pré-condições: usuário possui permissão efetiva para o tipo de registro; regime/ocorrência pertence ao contexto autorizado quando aplicável. Pós-condições: administração contém autoria/data-hora e integra histórico; original não é sobrescrito; N03 é emitida segundo regra.
