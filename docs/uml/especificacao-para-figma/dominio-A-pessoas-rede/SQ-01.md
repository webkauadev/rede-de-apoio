# SQ-01 — Sequência: Autenticação e Autorização

Status: **PRONTA PARA VALIDAÇÃO**. Objetivo: demonstrar que autenticação identifica a conta, mas autorização decide acesso contextual; inclui negação auditada.

Fonte de cenário: [REQUISITO] critérios aprovados de US-002 (#5673834103), US-035 (#5673867585) e US-036 (#5673868957). Não há cenário Gherkin formal versionado; estes critérios aprovados são a origem verificável e nenhuma formulação Gherkin será atribuída ao projeto. [ACADEMICO] slides 28–39 e 34 exigem ordem, alternativas e operação responsável.

Pré-condições: conta cadastrada/ativa para caminho válido; recurso protegido identificado para autorização. Pós-condições: sessão/autorização contextual permitida ou acesso negado sem expor recurso, com auditoria de negação.
